# 样例说明

本样例演示“节选剧本 → 候选 JSON”的转换结果，配套文件：

- `sample-input.md`：节选（E-001~E-008、E-012~E-014），逐字摘自 `Assets/Text/剧本.md`；
- `sample-output.json`：按 `conversion-rules.md` 转换得到的候选事件（命名空间 `E_0NN`）。

## 1. 转换总览（节选内）

| 来源事件 | 候选事件 | 说明 |
| --- | --- | --- |
| E-001 | `E_001`、`E_001_S`、`E_001_F` | 6 段叙述 → dialogue；“（检定：灵感）”直译为 insight 检定（灵感=已注册属性），分支文本进 S/F |
| E-002 | `E_002` | 便签内容 3 段 dialogue；背面/地图热点属场景层，进清单 |
| E-003 | `E_003` | 便签背面 3 段 dialogue |
| E-004 | `E_004`、`E_004_S`、`E_004_F` | 灵感检定直译 |
| E-005 | `E_005`、`E_005_S`、`E_005_F` | 灵感检定直译；成功侧含选择（继续前进→E-006、放弃前进→E-009）；失败侧 →E_006 |
| E-006 | `E_006A`/`E_006B` 及其分支 | “（若E-005灵感成功…）”在事件入口静态可追溯 → 拆成两个前置变体：E-005 成功侧进 A（SAN 0/1）、失败侧进 B（SAN 1/1d4），登记为自动推断 |
| E-007 | `E_007` | 医学为技能不可检定 → 原文占位行“（检定：医学）”，分支文本登记类别 C |
| E-008 | `E_008` | 侦查不可检定 → 占位行；尾部公共文本（“在不安的驱使下…五号车厢。”）照录并 next E-009 |
| E-012 | `E_012` | 发现乘务员叙述；乘务员热点进清单 |
| E-013 | `E_013` | 急救不可检定 → 占位行；成败分支（苏醒线→E-014 / 放弃线→E-017）与接线登记类别 C/H |
| E-014 | `E_014`、`E_014_SAND`、`E_014_TALK` | 叙述 +（乘务员）台词 → speaker 映射；SAN 0/1d2 按约定 C1 落地（成功→0 直达、失败→1d2 后合流）；话术不可检定 → 占位行 |

## 2. 关键转换决策示范（与 `conversion-rules.md` 条文对应）

1. **SAN 记法（§7，约定 C1）**：`SAN 0/1` → SAN 检定（check attribute=san），成功侧 0 损失直达端点（`E_006A_END`），失败侧损失 1（`E_006A_SAN1`）。
2. **骰子直译（§7）**：`1/1d4` 失败侧 → `custom modifyAttributeByDice`（count=1、sides=4），参数全部来自原文。
3. **前置变体拆分（§8）**：E-005 灵感成败直接决定 E-006 的 SAN 变体，把 E-006 拆为 `E_006A`（0/1）与 `E_006B`（1/1d4），避免运行时旗标路由。
4. **空动作端点（§6.2）**：`E_006A_END`/`E_006B_END` 为 `actions: []` 的事件，表示“检定某侧无事发生、回到场景”；编译器和运行时均接受（编译器只要求 actions 为数组，运行时空事件即完成）。
5. **合流（§4.2）**：`E_006B_SAN1` 与 `E_006B_SAND` 汇入 `E_006B_END`，公共文本不复制。
6. **占位行（§9）**：技能检定（医学/侦查/急救/话术）无法落地，事件内放原文整行占位（如“（检定：医学）”），分支文本不转录，只进审查清单。占位行是原文转录、非发明文本，人工落地后删除。
7. **说话人（§5）**：“（乘务员）正文”前缀提出后映射到 `speaker`；正文逐字保留。
8. **舞台指令（§5）**：（场景：抖动）（音效：惊悚凌厉）（场景：一半变黑）纯指令不入 JSON，登记类别 F；（主角表情：惊恐）这，这是什么！为“指令+正文”，整行原样转录。
9. **choice prompt（§5）**：剧本只有“（选择：…）”行无问句原文，`prompt` 置空串并在清单登记（不发明提示语）。
10. **场景动作**：E-006 位于 7 号车厢 → 在变体入口用 `changeScene`（引用既有真实场景 `carriage_07` 以便通过隔离编译）；其它车厢（4 号等）尚无真实场景，登记类别 E/H。

## 3. 本样例的边界（勿误解为成品）

- **切片外引用**：`E_009`（E-005 放弃项、E-008 尾跳）与 `E_017`（E-013 失败线）属于节选外事件，样例内**故意保留悬空引用**以展示结构；隔离编译验证时会注入临时 stub（空动作事件），仅存在于临时目录。
- `E_014` 在本节选内无入口事件（其入口是 E-013 苏醒线），为“孤儿事件”，编译可通过但暂不可达——真实落地需由 E-013 接线。
- E-005/E-006 车厢推进的真实热点物件（门/尸体/深处）需要场景与坐标，见审查清单 E/H 节。
- `E_008` 的侦查成败分支文本与 SAN 1/1d6 因技能不可检定而只在清单 C 节。
- 涉及“可重复调查/检定一次或多次”等触发拓扑问题全部留在清单 H 节，不擅自决定。
