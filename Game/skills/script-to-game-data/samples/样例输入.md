# 常暗之厢 · 事件剧本

## 事件 E-001 · 导入·醒来(灵感)

2013年的某天，你们搭乘本日的1号线末班电车。

目的地是终点站，车上的乘客无论是在加班后也好，还是参加了酒会后也好，都各自拖着疲累的身躯在车厢里陷入了深沉的睡眠。

由于睡得太熟，直到现在才醒来的你发现车厢里除了他们没有其他的乘客。

你并不清楚自己睡了多久，但电车还在继续奔走。

窗外没有任何街灯或照明，有如在漆黑的隧道中。

你发现所在车厢的门扉上贴着一张便签。

（可调查：门扉上的便签 → E-002）

（检定：灵感）：

    （分支1：成功）

    你察觉到现在明明早应该到了终点站了，不祥的预感在你心头笼罩。

    （分支2：失败）

    你没发现任何异常，或许你只是睡过了站。

### 事件 E-002 · 6号车厢·便签

门扉上贴着便签，写着：

「只管前进吧 已经没有退路了」

这是......什么意思？

（点击便签看背面 → E-003）

（可调查：门旁地图 → E-004）

#### 事件 E-003 · 6号车厢·便签背面

撕下便签查看背面，上面写着：

「第三个箱子里有藏着钥匙」

箱子？这里哪有箱子。

#### 事件 E-004 · 6号车厢·电车地图（灵感）

门扉旁有电车示意图。

（检定：灵感）：

    （分支1：成功）

    你仔细查看这张地图，忽然发觉哪里不对————

    7号车厢以后的地图是被人蓄意涂掉的。

    （分支2：失败）

    你努力查看这张地图，只能看出7号车厢以后的部分看不清楚。

### 事件 E-005 · 6号车厢·开门前（灵感）

（检定：灵感）:

    (分支1：成功)：

    你闻到一股浓重的血腥味，你觉得你不应该再前进了。

    （选择：继续前进→E-006；放弃前进→E-009）

    （分支2：失败）：

     
     你闻到一股浓重的血腥味，但在好奇心的驱使下，你还是决定继续前进。

    （→E-006）

#### 事件 E-006 · 7号车厢·开门后

（场景：抖动）

（音效：惊悚凌厉）

车厢内部，被撕裂的人类肢体散落一地。

（若E-005灵感成功：SAN 0/1）

（若E-005灵感失败：SAN 1/1d4）

（可调查：尸体 → E-007；车厢深处 → E-008）

#### 事件 E-007 · 7号车厢·调查尸体（医学）

尸体被浓浓的血浆覆盖着，四周散落着大大小小的尸块。

（检定：医学）:

    (分支1：成功)：

    你观察尸体，发现距离死亡时间并未过去很久。

    （分支2：失败）：
     
    你观察尸体，但并未发现任何异常。

#### 事件 E-008 · 7号车厢·深处侦查（侦查）

你颤抖着望向车厢深处

（场景：一半变黑）

（检定：侦查）:

    (分支1：成功)：

    眼前的景象让你动弹不得。

    车厢深处有巨大类似嘴巴的东西正在啃蚀车厢——那是某个比电车还要巨大的存在。
    
    （主角表情：惊恐）这，这是什么！

    （SAN 1/1d6）

    （分支2：失败）：
     
    原本应有8号车厢门的地方只剩一片漆黑，你感到莫名的不适。

    这是什么情况？

在不安的驱使下，你来到五号车厢。

（无分支，均进入E-009）

### 事件 E-012 · 4号车厢·发现乘务员

一进入车厢，你就发现一名重伤昏迷的乘务员倒在地上。

（可调查：乘务员 → E-013）

#### 事件 E-013 · 4号车厢·急救乘务员（急救）

（检定：急救）:

    (分支1：成功)：

    乘务员苏醒过来。

    （乘务员）啊...呃...天哪...

    (可对话 → E-014)

    （分支2：失败）：
    
    学校里教的那些急救知识你早已忘了个干净，不停颤抖的手也让你无法做完哪怕包扎这样最基础的动作。

    多次尝试无果后，你只能放弃对这位乘务员的救治。

    （ → E-017）

#### 事件 E-014 · 4号车厢·询问乘务员（话术）

乘务员表情十分痛苦，脸上不停地冒着冷汗，但你惊讶地发现她居然还能发出声音。

或许这就是逃离这里的钥匙。

您好，您还能说话吗，您知道这里发生了什么吗。

（乘务员）看...看起来像是人的怪物，突然间袭击了我们.
    
（乘务员）他们向着乘客一个一个咬去，有如野兽在捕食一般。
    
（乘务员）那场面简直像是人间地狱，到处都是惨叫。我当时在逃跑时候也被咬到了，万幸的是我跑了出来
 
你不敢相信这样人吃人的故事，但乘务员腿上的咬伤又强迫着你相信。

你硬着头皮，想要追问更多信息。

（SAN 0/1d2）

（检定：话术）:

    (分支1：成功)：

    那，那些怪物是怎么样的，您能想起来吗？

    （乘务员）样子...跑得太匆忙，我记不清了。

    （乘务员）但我记得他们对于声音似乎很敏感，我当时被咬伤的时候，疼的把手边的一个东西甩到了墙壁上，吸引了他们的注意力。

    （乘务员）呃啊...

    （分支2：失败）：

    冲击性的消息把你的脑子搅成一团乱麻，你不知道你该问什么。
