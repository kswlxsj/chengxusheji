# 末班列车网页游戏框架 v0.1

面向三周课程项目的原生 HTML/CSS/JavaScript 剧情运行框架。无需安装依赖，也无需 `npm run build`；解压后可直接双击 `index.html` 运行示例。

## 现在已经跑通的链路

新游戏属性加点 → 场景贴图 → 点击不规则物件 → 播放事件 → 流式文本 → 检定/选择 → 切换事件与场景 → 修改属性/技能/物品/物件可见性 → 单槽存档。

示例中可以：

1. 点击便签，获得旧车票，并让便签永久隐藏。
2. 点击门，进行一次依赖 `insight` 的 d100 检定。
3. 检定成功后选择是否进入 7 号车厢。
4. 在 7 号车厢调查收音机，查看派生自通用窗口的调查窗口。
5. 使用暂停菜单保存、返回主界面，以及对话的自动播放、快进与跳过本句。

打开游戏时会先显示带封面的主界面。已有存档时可以直接读取；选择新的游戏不会删除原有的手动存档。游戏中可按 `Esc` 或点击 HUD 的“暂停”打开暂停菜单。

新的游戏会在开场事件前显示一次属性加点窗口。玩家必须用完注册表中的全部点数才能确认；确认后只能由事件或自定义动作修改属性。技能可以由事件手动设置，也可以随相关属性变化自动生效或失效。

## 当前存档与物品栏

- 单槽存档以 `train-game-save-v1` 为键写入当前浏览器的 `localStorage`。存档内容使用 `saveVersion: 2`；旧版无版本存档会提示不兼容。它由浏览器用户配置管理，不会在项目目录中生成独立存档文件；清除该站点的浏览器数据会同时删除存档。
- 存档始终记录最近一次完整事件结束后的稳定状态。在对话、选择或演出进行中保存，得到的是该事件开始前的状态。
- 当前物品栏只在顶部 HUD 中显示已获得物品的名称。暂未提供可打开的物品栏窗口，也没有物品详情或主动使用物品的交互。

## 编辑数据

主要编辑：

- `data/events.json`：剧情事件与原子动作。
- `data/scenes.json`：背景、贴图物件、百分比位置和点击入口。
- `data/items.json`：物品定义。
- `data/attributes.json`：属性定义、初始值、上下限和新游戏可分配总点数。
- `data/skills.json`：技能定义、初始状态和可选的属性自动触发条件。
- `data/meta.json`：初始状态和入口。

游戏标题和主界面封面分别通过 `data/meta.json` 的 `title`、`coverImage` 配置。当前封面是 `assets/cover-placeholder.svg`，替换图片后修改 `coverImage` 路径即可。

项目已在 `.vscode/settings.json` 关联六份 Schema。用 VS Code 打开整个目录后，编辑这些 JSON 会直接获得字段补全和错误提示。

数据变动后运行：

```powershell
# 进入项目目录后，将六份 JSON 校验并编译成浏览器可直接加载的 JS 数据包。
npm run compile
```

完整检查：

```powershell
# 重新编译数据，并检查所有 JavaScript 文件是否存在语法错误。
npm run check
```

Node.js 只是内容编译工具；玩家运行游戏不需要 Node.js。
