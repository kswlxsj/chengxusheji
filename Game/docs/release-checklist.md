# 独立发布检查清单

本清单用于把当前目录作为完整课程项目私下交付给老师与玩家。发布物保留源码、开发工具、文档、Schema、skill、IE11 后备产物与小组介绍页，不包含上级美术源素材库 `Assets/`。

## 一、目录与依赖

- [ ] 从干净 Git 工作区制作发布副本。
- [ ] 发布根目录直接包含 `index.html`、`启动游戏.cmd`、`assets/`、`compat/`、`data/`、`src/`、`styles/`、`tools/` 与 `docs/`。
- [ ] 不包含 `node_modules/`、`.pnpm-store/`、`.playwright-cli/`、浏览器测试 profile、日志或临时文件。
- [ ] 保留 `data/compiled-game-data.js`、全部 `*.ie.*` 文件与 `compat/`；这些是运行产物，不是可删缓存。
- [ ] 若需要维护构建，在发布根目录执行 `pnpm install --frozen-lockfile`；玩家无需安装 Node.js。

## 二、自动检查

```powershell
npm run check
git diff --check
```

- [ ] 数据编译结果为 15 个场景、280 个事件、11 个物品、4 个属性、1 个技能、6 个小游戏、43 个音效。
- [ ] 独立布局下素材同步检查明确显示“未附带可选的上级 Assets 源素材库”并跳过；其他检查仍全部通过。
- [ ] 原始总仓库布局下存在上级 `Assets/` 时，素材同步检查必须严格通过，不得跳过失败项。

## 三、现代浏览器验收

- [ ] 双击 `启动游戏.cmd`，从其打开的 `index.html` 注册并登录；不要直接双击 HTML。
- [ ] 验证主页启动视频、视频加载失败时的静态后备、设置页、小组介绍汇总页及六个成员子页；控制台无 404 或非预期错误。
- [ ] 验证新游戏选槽、属性分配、首段剧情、暂停、保存、读取、刷新恢复与删除存档。
- [ ] 至少覆盖卡牌、交涉、收音机、控制杆小游戏，以及六类结局入口与感谢视频。
- [ ] 分别试听真结局、SAN 归零、站台离场与 E-011 警报音频；以对应剧情目的为准，不以文件名或哈希是否重复作为失败条件。

## 四、IE 模式验收

- [ ] 按 [`browser-compatibility.md`](browser-compatibility.md) 配置 Edge IE 模式并完成其中的全流程清单。
- [ ] 登录、存档、剧情、物件点击、小游戏和结局不得中断；字体、渐变与装饰动画允许按文档约定降级。
