# 常暗之厢 · 事件剧本

## 事件 E-001 · 导入·醒来（灵感）

2013年7月15日，你搭乘1号线末班电车，目的地是终点站。

站台上已经空无一人，车厢内的人们稀稀疏疏，各自找到座位坐下来。

静谧中，车门关闭的刺耳提示音响起，电车缓缓发动。

疲惫的你感到眼皮发沉。离终点站还有很久，你在车厢里沉沉入睡。

......

不知过了多久，你醒了，空气莫名有些阴冷。

也许是电车的空调开得太足，你没有多想。

由于睡得太熟，你并没有电车停靠过哪些站点的具体印象。

你想打开手机看看时间，但是已经关机了。

你环顾四周，这节车厢除你之外还有5名乘客。

其中一个男人靠着玻璃睡觉，旁边女人手里拿着一本翻开的杂志，也闭着眼，看起来睡着了......

你轻拍女人的肩，想问问她现在几点了。

没有反应。

你小声呼唤“这位先生”，尝试叫醒男人。

还是没有反应。

突然，电车一个急转弯。

男人调整了一下睡姿。

你心想,还是先不要打扰别人好了。

对面的车窗上玻璃上，你能清晰地看见自己的脸夹在几个沉睡乘客之间。

车厢的灯光忽闪，女人的影子不见了。

你转头。

她好端端坐着。

窗外没有任何街灯或照明，电车犹如驶在漆黑的隧道中。

广播忽然响起:

“下一站——”

声音戛然而止，只剩下电流的嘶嘶声。

几秒以后：

“下一站——”

还是中断。

第三次：

“终点站到了。”

但车没有减速。

（检定：灵感）

    （分支1：成功）

     你察觉到现在明明早应该到了终点站了，不祥的预感在你心头笼罩。

     忽然，你发现斜对面的门扉上贴着一张泛黄的便签。

     （→ E-002）

    （分支2：失败）

     你没发现任何异常，或许还没到站，疲惫使你继续睡了过去。

     半梦半醒之间，广播再次响起——

     “下一站——”

     你猛地睁开眼。电车仍在行进，窗外的黑暗一成不变，而门扉上不知何时多了一张泛黄的便签。

     （→ E-002）

### 事件 E-015 · 4号车厢·询问乘务员（话术）

乘务员表情十分痛苦，脸上不停地冒着冷汗，但你惊讶地发现她居然还能发出声音。

或许她知道些什么，能帮你们逃离，你得抓紧时间了。

她伤得太重，你只有三次提问的机会。每次提问都有两种问法——你的选择，会决定她告诉你什么，也会改变她对你的信任。

【对话组一 · 让她开口】

（选择A1：安抚）

（A1）你先别急，深呼吸。你现在安全了。告诉我，这班车到底发生了什么？

乘务员闭着眼喘了很久，终于断断续续地开口：

（乘务员）...我是从7号车厢一路逃过来的。最开始，是后面传来惨叫...车灯开始一闪一闪...然后它们就出现了。像人，又不是人。见人就咬，跑得慢的，都被扑倒了...

她忽然望向车窗外，意识到电车仍在行进，脸色骤变：

（乘务员）车...车怎么还在开？！得让它停下来！停下来，我们才能逃出去！

【情报·袭击始末】怪物从后部车厢开始袭击；幸存者一路向车头方向逃亡。

【状态·平稳】她叙述相对完整，对你的信任增加。

（选择A2：鼓励）

（A2）振作起来，告诉我发生了什么！我们再不逃就没命了！

乘务员被你吓得一抖，语无伦次：

（乘务员）跑...一直在跑！我的包...包带被切断了，钥匙在里面！驾驶室的钥匙！我本来想...想跑到车头去...

她死死抓住你的手腕：

（乘务员）车不能继续开下去...再往前，会撞上什么的...会撞上...

她忽然咬住话头，自己也说不清“再往前”会怎样。

【情报·黑包线索】她随身携带的黑色背包里有两把钥匙（驾驶室钥匙、操作面板钥匙），逃跑途中背带被切断，包已遗失。她此刻记不清具体位置（E-016将确认）。

【状态·惊惧】她情绪不稳，叙述破碎，对你的信任没有明显变化。

【对话组二 · 追问关键】

（检定：话术）

（选择B1：追问怪物）

（B1）那些东西长什么样？有什么弱点？

    （检定成功）

     （乘务员）它们...没有眼睛。眼眶是空的。可是耳朵很灵，一点点声音就会扑过来。我当时撞倒了东西，它们全朝那边去了...

     你想起一路上那些窸窣的动静——原来它们一直在循声。

     【情报·怪物习性】怪物无眼、循声而动、对声音极度敏感。

    （检定失败）

     （乘务员）样子...跑得太匆忙，我记不清了。

     她费了好大的劲，只挤出几个字：

     （乘务员）没有眼睛...别出声...它们听得到...

     【情报·怪物习性·碎片】你只隐约知道它们对声音敏感，其余一无所知。

（选择B2：追问如何停车）

（B2）驾驶室在哪？有没有办法让车停下来？

（乘务员）车头...最前面。我本来已经快到了...

她低头看着自己的伤腿，忽然困惑地皱起眉：

（乘务员）我是在2号车厢被咬的...不对...是在7号...

她的声音越来越小，自己也说不清了。

你问：“你到底是几号车厢受的伤？”

她沉默了许久，慢慢地说：

（乘务员）...我说过吗？

【情报·驾驶室】驾驶室在车头（先头）方向，进入后可以控制电车。

乘务员对自己受伤车厢的记忆互相矛盾，而且她似乎并不记得自己刚刚说过什么。

【对话组三 · 钥匙与嘱托】

乘务员望着你，眼神忽然变得很奇怪：

（乘务员）...没什么,我认错人了。

她压低声音，凑近你：

（乘务员）黑包掉在3号车厢前门附近。驾驶室钥匙和操作面板钥匙，都在里面。

随即她盯着你的眼睛，一字一句地说：

（乘务员）答应我...拿到钥匙以后，把车停下来。停下来，我们才能逃出去。

【情报·钥匙位置】黑包在3号车厢前门附近，内含两把钥匙。

【信任·高】她愿意跟你走。

（若在E-017选择背起她，她会尽量配合、压低重心，减少你的负担。）

她似乎见过你——“又回来”意味着什么？

（选择C2：质疑）

（C2）可如果停车，后面的东西会追上来。而且这一路上，便签上、报纸上的字，都在让我们继续前进。

乘务员的脸色变了：

她剧烈地喘着，仿佛在说服你，也在说服自己：

（乘务员）钥匙在包里...包在3号...不，4号...不对...

她的记忆再次动摇。你耐着性子，让她慢慢想。

### 事件 E-031 · 先头车厢·进入驾驶室

（若钥匙由主角保管）

（若钥匙由乘务员保管）

她颤抖着摸出钥匙，替你打开门。

你注意到，她看向驾驶室的目光里，有一种近乎执念的光。

（若仍未获得钥匙）

你伸手推了推门——锁着。

（检定：侦查 · 第二次）

    （分支：成功）

### 事件 E-032 · 先头车厢·操作面板与拉杆

- 右杆（油门）——在中间

操作台边缘的灰尘里，有人用手指写了一行字：

**MOVE FORWARD**

### 事件 E-033 · 先头车厢·乘务员干预

（检定：话术/魅惑/力量对抗，调查员力量 +20%补正）

（若E-015选择C2【信任·低】：检定难度 +10%）

（若E-021钥匙由乘务员保管：她离操作台更近，检定难度 +10%）

     （乘务员）对不起...对不起...我只是想活...

### 事件 E-034 · 结局A · True End

电车加速到极致，视野被刺眼白光覆盖。

你睁开眼，发现自己仍坐在6号车厢。

广播声响起————

终点站已到。

站务人员走来询问：你们脸色不好，没事吧？

车厢里的人们陆续醒来，揉着眼睛下车。

你翻看背包：便签、报纸、手机、手电筒——全都不在了。

那是一场共同的噩梦。恐怖的记忆慢慢淡忘。

你跟在人群后面走出站台。

身后，末班电车的车门缓缓关闭。

抬头，你看见站台的指引牌，不知什么时候换成了，写着熟悉字迹的————

「MOVE FORWARD」

### 事件 E-035 · 结局B · Bad End

拉杆减速，列车停下的瞬间，四周陷入漆黑。

嘎吱嘎吱的咀嚼声接近，脚下流过粘稠血水与残骸。

你想起一路上那些字：

「MOVE FORWARD」

你停下的那一刻，就已经输了。

意识与身体一同消失...

在座位上醒来，分不清梦境与现实。啃食声挥之不去，从此恐惧度日。

你发现背包里多了一个背带被切断的黑色包。

（SAN 减少 1d4/1d10）

### 事件 E-036 · 结局C · Crazy End

在隔离室中醒来，你蜷缩在墙角。

医生对警察摇了摇头，表情无奈：每天都要镇定剂，突然就疯掉了。

你因在梦中经历了无法承受的恐怖，醒来后歇斯底里，被送进精神病院。

无人知晓你们在逃避什么。

（SAN 归零）

【新增机制说明】

- 报纸联动：E-019 重读报纸时，若乘务员未同行（留在4号或昏迷），人数从“22名乘客获救”变为“21名乘客获救”，少掉的是玩家自己——用于驱动玩家折返救她。若乘务员同行，文字维持22人版。
- 二次急救：E-014 急救失败后，可在 E-020 返回4号时再次急救。成功 → 乘务员同行（虚弱，只能提供呓语级情报）；失败 → 乘务员死亡，报纸再读变为“21名乘客获救。现场未发现幸存乘务人员。”
- 乘务员死亡惩罚：E-029 敏捷对抗、E-030 力量对抗成功率均 -80%（失败率 +80%）；检定失败或被两只以上 Clicker 抓住 → E-036 结局C，无法进入先头车厢。

【结局条件】

- 结局A（True End，E-034）：E-032下拉右杆加速；若乘务员同行，需在E-033中成功阻止她停车。
- 结局B（Bad End，E-035）：E-032上拉右杆减速；或乘务员在E-033中抢先减速（干预失败）。
- 结局C（Crazy End，E-036）：E-029/E-030被Clicker抓住无法挣脱；或E-031始终未能找到钥匙开门。

【主题核对】

乘务员的声音始终是“停车，逃出去”；而世界的声音（便签「MOVE FORWARD」、报纸「DON'T STOP」、手机短信「不要停车」、操作台灰尘字迹）始终是“前进，不要停”。二者冲突自E-002埋下，在E-016/E-018/E-020正面碰撞，于E-032/E-033的驾驶室二选一中收束，并由E-034（加速/True）与E-035（停车/Bad）给出裁决。
