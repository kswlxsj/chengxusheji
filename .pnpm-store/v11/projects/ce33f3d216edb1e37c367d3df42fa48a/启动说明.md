# 游戏启动说明

本游戏由多个网页组成，账号、登录会话和存档都保存在浏览器中。为了让各页面可靠共享状态，必须通过本地静态服务器访问，不能直接双击 `index.html`。

任何方式都要求：服务器根目录是 `Game` 文件夹（即包含 `index.html` 的那一层），所有页面使用完全相同的协议、主机和端口，并且始终从 `index.html` 进入游戏。

## 推荐：VS Code Live Server

1. 用 VS Code 打开 `Game` 文件夹。
2. 安装并启用 Live Server 扩展。
3. 在 `index.html` 上右键，选择 **Open with Live Server**。
4. 浏览器会自动打开形如 `http://127.0.0.1:5500/` 的地址。

## 其他常见方式

在 `Game` 目录下启动任意静态服务器，例如：

```powershell
python -m http.server 8000 --bind 127.0.0.1
py -m http.server 8000 --bind 127.0.0.1        # 找不到 python 时
npx serve .
npx http-server -p 8000
```

macOS / Linux 使用 `python3 -m http.server 8000 --bind 127.0.0.1`，也可以改用 nginx、Apache 等。

## 存档与登录

- 三个正式存档槽和注册账号保存在浏览器 `localStorage` 中，不写入项目文件夹；所有账号共用同一组存档槽。
- 登录状态保存在 `sessionStorage` 中，关闭标签页后失效，需要重新登录。
- 更换浏览器、访问地址（如 `localhost` 与 `127.0.0.1`）、端口，或使用无痕窗口、清除站点数据，都会让原存档不可见。请固定使用同一个浏览器和同一个地址。
- 游戏事件或对话尚未结束时不能保存，完成后从暂停菜单保存。
- 纯前端课程演示，密码以明文保存，请勿使用真实密码。

## 常见问题

- **页面缺少图片、按钮无反应或 404**：确认服务器根目录是 `Game` 文件夹，不要移动或单独复制 HTML、`src`、`data`、`styles`、`assets` 中的文件。
- **浏览器显示文件列表**：服务器从错误的文件夹启动，改在 `Game` 目录下重新启动。
- **端口被占用**：换一个端口（如 8001）；之后读取这次存档时要继续使用该端口。
- **修改后仍显示旧内容**：按 `Ctrl + F5` 强制刷新，刷新前确认进度已保存。
- **存档不见了**：检查是否使用了原来的浏览器、地址和端口，是否进入无痕窗口或清理过站点数据。
