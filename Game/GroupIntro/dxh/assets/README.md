# 照片资源

将带透明通道的个人照片放在此目录并命名为 `profile.png`，页面会自动载入。

- 支持竖图、横图、方图及高分辨率照片，建议保留人物周围需要展示的透明边缘。
- 页面使用 `object-fit: contain` 完整展示图片，不拉伸、不裁剪。
- 页面不会增加遮罩或颜色滤镜；照片会以 60% 不透明度展示，PNG 的透明区域会直接显示动态背景。

## 方向卡片图片

三张“探索方向”卡片默认显示“图片待补充”占位。需要加入图片时，将图片放在本目录，并在 `index.html` 对应卡片的 `.work-card__media` 中用带有准确 `alt` 文本的 `<img>` 替换占位文字。

- 卡片媒体区固定为 `16:10` 比例，建议优先准备相同比例的素材。
- 横图、竖图和其他比例的图片都会居中裁切并铺满媒体区，不会拉伸；请将主要内容放在画面中央附近。
- 图片占位与真实图片使用相同尺寸，添加图片不会改变卡片内容的起始位置。

Markdown 正文也可以引用本目录中的图片。路径相对于项目根页面书写，例如 `![项目界面](assets/project-preview.png)`；远程图片也会被正常加载，因此若要页面完全不依赖外网，请使用本地图片。
