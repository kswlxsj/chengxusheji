# 游戏启动说明

本游戏由多个网页组成，存档保存在浏览器中。为了让主页、游戏页和存档页可靠地共享存档，必须通过本地静态服务器访问，不能直接双击 `index.html` 开始游戏。

## 一、推荐启动方式（Windows）

### 第一步：找到游戏目录

解压或下载完整项目后，进入 `Game` 文件夹。请确认其中能看到以下文件：

```text
index.html
game.html
save-manager.html
save-write.html
```

不要单独复制某个 HTML 文件运行，否则图片、脚本和游戏数据会缺失。

### 第二步：在当前文件夹打开 PowerShell

在文件资源管理器顶部的地址栏中输入：

```text
powershell
```

按 Enter。新打开的 PowerShell 窗口应位于 `Game` 文件夹。

也可以先打开 PowerShell，再使用 `cd` 进入 `Game` 文件夹。

### 第三步：启动本地服务器

如果电脑已经安装 Python，运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

如果提示找不到 `python`，可以尝试 Windows 的 Python 启动器：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

出现类似下面的信息表示启动成功：

```text
Serving HTTP on 127.0.0.1 port 8000 ...
```

游戏运行期间不要关闭这个 PowerShell 窗口。

### 第四步：在浏览器中打开游戏

打开 Chrome、Edge 或 Firefox，在地址栏输入：

```text
http://127.0.0.1:8000/
```

看到游戏主页后即可选择“新的游戏”“存档管理”“设置”或“小组介绍”。不要把 `index.html` 拖进浏览器，也不要使用以 `file:///` 开头的地址。

## 二、以后如何再次启动

每次重新开机或关闭服务器后，都需要：

1. 在 `Game` 文件夹打开 PowerShell。
2. 再次运行启动服务器的命令。
3. 使用同一个浏览器打开 `http://127.0.0.1:8000/`。

只关闭游戏标签页不会删除正式存档。服务器停止后存档仍保存在浏览器中，下次按相同方式启动即可继续读取。

## 三、如何关闭游戏服务器

回到正在运行服务器的 PowerShell 窗口，按：

```text
Ctrl + C
```

服务器停止后，已经打开的游戏页面将无法继续载入其他页面；重新运行启动命令即可恢复访问。

## 四、存档注意事项

- 三个正式存档槽保存在浏览器的 `localStorage` 中，不会写入项目文件夹。
- 请固定使用相同的浏览器和地址 `http://127.0.0.1:8000/`。
- 改用 `localhost`、其他端口或其他浏览器时，浏览器会把它视为另一份独立存储，原存档不会显示。
- 无痕或隐私浏览窗口关闭后通常会清除其中的存档。
- 清除该地址的站点数据、重置浏览器配置或卸载浏览器，可能删除存档。
- 游戏事件或对话尚未结束时不能保存；完成当前事件后再打开暂停菜单。

## 五、其他启动方式

Python 不是游戏的必需组件，只是用于启动静态服务器。也可以使用任何能够把整个 `Game` 文件夹放在同一地址下的静态服务器，例如 VS Code Live Server、Node.js 静态服务器、nginx 或 Apache。

使用其他工具时仍需满足：

1. 服务器根目录是 `Game` 文件夹。
2. 所有页面使用完全相同的协议、主机和端口。
3. 始终从主页 `index.html` 进入游戏。

macOS 或 Linux 通常可以在 `Game` 目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

## 六、常见问题

### 提示“python 不是内部或外部命令”

先尝试 `py -m http.server 8000 --bind 127.0.0.1`。如果仍然失败，需要安装 Python，或改用 VS Code Live Server 等静态服务器。

### 提示端口已被占用

可能已经有一个服务器在运行。先尝试打开 `http://127.0.0.1:8000/`。如果无法使用，可以换一个端口，例如：

```powershell
python -m http.server 8001 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8001/`。注意：8000 和 8001 对应不同的浏览器存储；以后读取这次存档时应继续使用 8001。

### 浏览器显示“无法访问此网站”或 `ERR_CONNECTION_REFUSED`

确认服务器窗口仍在运行，并检查浏览器地址和命令中的端口是否一致。如果服务器已经关闭，请重新启动。

### 浏览器显示文件列表，而不是游戏主页

说明服务器可能从错误的文件夹启动。停止服务器，进入包含 `index.html` 的 `Game` 文件夹后重新运行命令；也可以在文件列表中点击 `index.html` 临时进入主页。

### 页面缺少图片、按钮无反应或出现 404

确认项目目录完整，并且服务器根目录是 `Game` 文件夹。不要移动或单独复制 HTML、`src`、`data`、`styles`、`assets` 中的文件。

### 修改后浏览器仍显示旧内容

在页面中按 `Ctrl + F5` 强制刷新。刷新前请先确认当前进度已经保存。

### 原来的存档不见了

依次检查：

1. 是否使用原来的浏览器和用户配置。
2. 是否仍使用相同的地址和端口。
3. 是否进入了无痕窗口。
4. 是否清理过浏览器站点数据。

旧版单槽存档不会自动迁移到当前三个存档槽中。
